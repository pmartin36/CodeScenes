# Changelog

All notable changes to CodeScenes are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.0.0/), and the project aims to follow
[Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- Bidirectional code<->scene sync: edit the scene and the builder source updates; edit the source and
  the scene updates, with no manual step.
- In-editor licensing for the direct channel: key activation, three-machine seat management, and a
  14-day trial.
- Declared Unity module dependencies (physics, ui, uielements, imgui, audio, unitywebrequest,
  jsonserialize) so the package installs and compiles in any project.
